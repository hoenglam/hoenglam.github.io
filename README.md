# Minecraft Ecosystem Research website

A bilingual project website maintained by **hoenglam**, exploring innovation, interdependence, and project evolution in the Minecraft modding ecosystem.

- Website: https://hoenglam.github.io/
- Research documentation and code: https://github.com/hoenglam/minecraft-ecosystem-research

## Publishing

This is a static website with no build dependencies. GitHub Pages publishes the `main` branch from the repository root (`/`). The `.nojekyll` file keeps the site as plain static files.

In the repository's **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**. Changes committed to `main` are published automatically after the Pages deployment completes.

To preview locally, open `index.html` in a browser. The Chinese/English toggle and local assets work without installing packages.

## 自行修改内容

在 GitHub 仓库中打开相应文件，点击编辑按钮，修改并提交到 `main`。等待 Pages 发布完成后，刷新网站即可查看更新。

| 想修改的内容 | 文件 |
| --- | --- |
| 英文介绍、研究项目、页面链接 | `index.html` |
| 中文介绍与其他中文文案 | `site.js` |
| 颜色、字体、间距和页面布局 | `styles.css` |
| 浏览器标签页图标 | `favicon.svg` |

中英文文案需要分别修改。编辑时保留 HTML 标签以及 JavaScript 中的引号、逗号和括号。可以先在本地预览，再提交更新。

网站和这个仓库均公开访问；请仅加入希望公开的项目内容。不要上传 API 密钥、私人资料或未获授权共享的数据。

## Scope

The diagram is conceptual. The project is exploratory and this website does not report empirical findings or distribute mod files. Research data and code belong in the separate research repository linked above.
